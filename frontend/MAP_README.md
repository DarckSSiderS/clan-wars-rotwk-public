# Интерактивная карта - React компонент

## Обзор

Интерактивная карта представляет собой React компонент, который отображает SVG карту с интерактивными регионами. Карта поддерживает зум, полноэкранный режим и отображение информации о регионах.

## Структура файлов

```
frontend/src/
├── pages/
│   ├── MapPage.jsx          # Основной компонент страницы карты
│   └── MapPage.css          # Стили для карты
├── data/
│   └── mapRegions.js        # Данные регионов карты (для будущего использования)
├── components/
│   └── Navigation.jsx       # Навигация (добавлена ссылка на карту)
└── public/
    ├── map.svg              # Оригинальная SVG карта (неинтерактивная)
    └── map-interactive.svg  # Интерактивная SVG карта с фоном и регионами
```

## Функциональность

### Основные возможности:
- **Интерактивная карта**: Оригинальная SVG карта с интерактивными регионами
- **Интерактивные регионы**: Клик по регионам для получения информации
- **Hover эффекты**: Наведение для предварительного просмотра с подсветкой
- **Зум**: Увеличение/уменьшение карты (1x - 10x)
- **Панорамирование**: Перетаскивание карты мышью
- **Зум колесиком**: Масштабирование колесиком мыши к позиции курсора
- **Сброс масштаба и позиции**: Возврат к исходному состоянию
- **Полноэкранный режим**: Просмотр карты на весь экран
- **Адаптивность**: Поддержка мобильных устройств
- **Информационные панели**: Отображение названия и описания территорий

### Панель управления:
- **Увеличить** (ZoomIn): Увеличить масштаб карты
- **Уменьшить** (ZoomOut): Уменьшить масштаб карты
- **Сбросить масштаб** (RestartAlt): Вернуть к исходному масштабу и позиции
- **Сбросить позицию** (CenterFocusStrong): Вернуть карту в центр
- **Полноэкранный режим** (Fullscreen): Переключить полноэкранный режим

### Управление картой:
- **Перетаскивание**: Зажмите левую кнопку мыши и перетаскивайте карту
- **Зум колесиком**: Используйте колесико мыши для масштабирования
- **Зум к курсору**: Масштабирование происходит к позиции курсора
- **Свободная навигация**: При приближении можно перемещаться по всей карте
- **Плавные анимации**: Плавные переходы при изменении масштаба и позиции

### Категории регионов:
- Красные земли (опасные территории)
- Коричневые земли (пустынные территории)
- Зеленые земли (лесные территории)
- Синие земли (морские территории)
- Желтые земли (золотые территории)
- Фиолетовые земли (мистические территории)
- Оранжевые земли (вулканические территории)

## Использование

### Добавление в навигацию:
Карта уже добавлена в навигацию как "Карта" между "Войны" и "Магазин".

### Роутинг:
Карта доступна по адресу `/map` и защищена авторизацией.

### Полноэкранный режим:
- Нажмите кнопку полноэкранного режима для переключения
- В полноэкранном режиме карта занимает весь экран
- Прокрутка страницы отключена в полноэкранном режиме
- Выход из полноэкранного режима через кнопку или ESC

### Масштабирование и навигация:
- Используйте кнопки "+" и "-" для изменения масштаба
- Используйте колесико мыши для зума к позиции курсора
- Зажмите левую кнопку мыши и перетаскивайте для панорамирования
- Карта ограничена границами контейнера и не может выйти за них
- Кнопка сброса возвращает к исходному масштабу и позиции
- Кнопка сброса позиции возвращает карту в центр
- Поддерживается масштаб от 1x (100%) до 10x (1000%)

## Стилизация

### CSS классы:
- `.region` - базовые стили для всех регионов
- `.region:hover` - эффекты при наведении
- `.region.selected` - стили для выбранного региона
- `.category-name` - стили для конкретной категории
- `.fullscreen-map` - стили для полноэкранного режима
- `.control-panel` - стили панели управления

### Цветовая схема:
Каждая категория имеет свой цвет:
- Красные земли: #8B0000
- Коричневые земли: #8B4513
- Зеленые земли: #228B22
- Синие земли: #000080
- Желтые земли: #B8860B
- Фиолетовые земли: #4B0082
- Оранжевые земли: #FF8C00

## Локализация

Карта поддерживает локализацию через `useLocalizationContext`. Ключи локализации:
- `map_title` - Заголовок страницы
- `map_description` - Описание карты
- `map_type_interactive` - Интерактивная карта
- `map_type_original` - Оригинальная карта
- `map_zoom_in` - Увеличить
- `map_zoom_out` - Уменьшить
- `map_reset_zoom` - Сбросить масштаб
- `map_fullscreen` - Полноэкранный режим
- `map_exit_fullscreen` - Выйти из полноэкранного режима
- `map_legend` - Легенда
- `map_region_id` - ID региона

## Технические детали

### Состояние компонента:
- `scale` - текущий масштаб карты
- `position` - текущая позиция карты (x, y)
- `isDragging` - флаг перетаскивания
- `dragStart` - начальная позиция перетаскивания
- `isFullscreen` - флаг полноэкранного режима
- `selectedRegion` - выбранный регион
- `hoveredRegion` - регион под курсором
- `svgContent` - загруженное содержимое SVG
- `svgRef` - ссылка на DOM элемент SVG

### Интерактивность регионов:
- Автоматическое обнаружение всех `<path>` элементов в SVG
- Добавление обработчиков кликов и наведения
- Динамическая подсветка при наведении (голубой цвет)
- Выделение выбранных регионов (красный цвет)
- Отображение информации о регионе в информационной панели

### Обработка событий:
- `fullscreenchange` - отслеживание изменений полноэкранного режима
- `mousedown/mousemove/mouseup` - панорамирование карты с ограничениями
- `wheel` - масштабирование колесиком мыши с ограничениями позиции
- `click` - выбор региона
- `mouseenter/mouseleave` - hover эффекты для регионов

### Ограничения перемещения:
- При масштабе 1x (100%) карта остается в центре без возможности перемещения
- При масштабе больше 1x разрешается свободное перемещение по всей карте
- Горизонтальное смещение: коэффициент 650 для широкого обзора
- Вертикальное смещение: коэффициент 500 для более контролируемого движения
- Максимальное смещение пропорционально текущему масштабу
- Область перемещения оптимизирована для комфортной навигации
- Пользователи могут исследовать всю карту с разумными ограничениями

### Производительность:
- Плавные анимации масштабирования
- Оптимизированная отрисовка SVG
- Адаптивная загрузка изображений
