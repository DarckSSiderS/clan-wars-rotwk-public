# ClanWar Frontend

Современное React приложение для системы клановых войн.

## Технологии

- **React 18** - Основная библиотека для создания пользовательского интерфейса
- **Vite** - Быстрый инструмент сборки
- **Material-UI (MUI)** - Компонентная библиотека для современного дизайна
- **React Router** - Маршрутизация в приложении
- **Axios** - HTTP клиент для работы с API
- **Context API** - Управление состоянием приложения

## Структура проекта

```
src/
├── components/          # Переиспользуемые компоненты
│   ├── Navigation.jsx   # Навигационное меню
│   └── ProtectedRoute.jsx # Защищенные маршруты
├── contexts/            # React контексты
│   └── AuthContext.jsx  # Контекст аутентификации
├── pages/               # Страницы приложения
│   ├── LoginPage.jsx    # Страница входа
│   ├── RegisterPage.jsx # Страница регистрации
│   ├── DashboardPage.jsx # Главная страница
│   ├── ClansPage.jsx    # Список кланов
│   ├── WarsPage.jsx     # Клановые войны
│   └── ProfilePage.jsx  # Профиль пользователя
├── services/            # Сервисы для работы с API
│   ├── api.js          # Базовый API клиент
│   ├── authService.js  # Сервис аутентификации
│   └── clanService.js  # Сервис для работы с кланами
├── hooks/               # Пользовательские хуки
├── utils/               # Утилиты
├── App.jsx             # Главный компонент приложения
└── main.jsx            # Точка входа
```

## Функциональность

### Аутентификация
- Регистрация новых пользователей
- Вход в систему с JWT токенами
- Автоматическое перенаправление при истечении токена
- Защищенные маршруты

### Профиль пользователя
- Просмотр информации о пользователе
- Редактирование профиля
- Загрузка аватара
- Статистика пользователя

### Кланы
- Просмотр списка всех кланов
- Поиск кланов
- Информация о кланах и участниках
- Подача заявок в кланы

### Клановые войны
- Просмотр активных и предстоящих войн
- Информация об участниках и счетах
- Статусы войн (активная, предстоит, завершена)

## Запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер разработки:
```bash
npm run dev
```

3. Приложение будет доступно по адресу: http://localhost:3000

## Сборка для продакшена

```bash
npm run build
```

## Конфигурация

Приложение настроено для работы с бэкендом на порту 8000. Проксирование API запросов настроено в `vite.config.js`.

## Особенности

- Современный Material Design интерфейс
- Адаптивный дизайн для мобильных устройств
- Автоматическое управление состоянием аутентификации
- Обработка ошибок и загрузки
- TypeScript готовность (можно легко мигрировать)
