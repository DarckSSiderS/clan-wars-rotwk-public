# ROTWK ClanWars

Это сайт для клановых войн в Rise of the Witch-king. Здесь можно вступить в клан, захватывать земли на карте Средиземья, развивать их и торговать с другими кланами.

Для участия привяжи аккаунт BFME Arena. Подходящие рейтинговые матчи сайт засчитывает в битвы автоматически.
