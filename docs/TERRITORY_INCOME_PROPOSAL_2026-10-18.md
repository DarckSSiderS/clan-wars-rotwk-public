## Как Сопоставлены Категории

- Старые категории frontier/standard → обычная земля: 100 золота + 4 профильного материала в сутки.
- valuable → богатая: 150 + 6; hub → особо ценная: 200 + 8.
- Порт без крепости → 150 + 4. Признак порта не добавляет второй доход.
- Мифриловые земли: Врата Мории → 150 + 1 мифрил; Перевал Карадрас → 100 + 1 мифрил. Конкретные значения внутри согласованного диапазона предлагаются на подтверждение.
- Крепости: прежние minor/major/capital → 300/350/400 золота. Предлагается один основной материал по 8 в сутки, без прежнего второго ресурса. Это **предложение**, а не уже утверждённый доход крепостей.
- Влияние показано существующее: 50 для обычных земель, 90/120/160 для крепостей. Это не расходуемый ресурс. Новых значений влияния этим документом не утверждаем.
- Все суммы до улучшений и реликвий. Базовый доход клана 100 золота + 2 железа + 2 дерева + 2 еды в сутки начисляется отдельно, один раз клану.

## Перед Активацией

1. Подтвердить спорные строки, включая основной ресурс и 8/сутки у крепостей.
2. Сверить с актуальной картой будущего сезона; неизвестная или изменённая земля блокирует импорт, а не получает ресурс по умолчанию.
3. Сформировать явные сезонные профили по ID и проверить полноту для всех игровых земель. Старый второй ресурс и портовую надбавку автоматически не переносить.
4. Применять только при отдельно разрешённом локальном запуске/сбросе нового сезона. Настоящий документ не выполняет импорт, миграцию или изменение владений.
