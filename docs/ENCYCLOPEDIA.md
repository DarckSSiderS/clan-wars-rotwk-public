# Энциклопедия

Публичная страница `/encyclopedia` встроена в основную и мобильную навигацию ClanWars. В ней представлены вкладки **Ennorath** и **2.02**. Сейчас выбран Ennorath; кнопка 2.02 недоступна, поскольку модели этой версии ещё не перенесены. Общий переключатель рейтингового патча в шапке сайта работает независимо от каталога моделей.

## Каталог Ennorath

В сайт перенесены все 54 подключённые сущности исходного проекта `website-viewer`: Гондор, Рохан, Арнор, Лотлориэн, Эребор и Мордор. Доступны поиск, фильтры фракции и типа, постоянные ссылки вида `?entity=aragorn`, уровни, характеристики и способности.

Просмотрщик показывает настоящие игровые GLB, проигрывает анимации, переключает оружие и облики, показывает отрядную формацию. Уровневые облики и стадии зданий меняются при изменении уровня. Есть пауза, сброс камеры, отмена загрузки при уходе, освобождение графических ресурсов и повтор после ошибки. При предпочтении уменьшенного движения анимация изначально остановлена.

Все ресурсы раздаются с сайта. Запущенный `website-viewer` или установленная игра не нужны. Three.js загружается отдельным модулем при открытии энциклопедии; модели запрашиваются по выбранной сущности. Используются React, общая навигация, языковой контекст и визуальные переменные ClanWars.

## Локализация и границы данных

Интерфейс и названия сущностей доступны на ru/en/de. Исходные описания способностей и примечания к характеристикам сохранены на русском; в английском и немецком интерфейсе это явно обозначено, элементы имеют `lang="ru"`.

Каталог содержит уже перенесённые 54 сущности, а не все 426 записей технического реестра исходного проекта. Характеристики относятся к сборке исходного архива, а не автоматически к последней версии мода. Сохранён исходный расчёт здоровья и урона по уровням; для строений второе числовое поле подписано как стоимость, для фермы Рохана — доход за цикл.

## Ресурсы и обновление

`frontend/public/encyclopedia/ennorath/` содержит `catalog.json`, `manifest.json`, 123 GLB и 151 изображение общим размером около 204 МиБ. Контрольные суммы SHA-256 совпадают с исходным проектом. Копируются только файлы, на которые ссылаются подключённые профили.

Повторный импорт из доверенного локального проекта:

```powershell
cd C:\Dev\clan_wars_ROTWK-vds\frontend
npm.cmd run import:ennorath -- C:\Users\Alitryel\Documents\ChatGPT\website-viewer
npm.cmd run check:archive
npm.cmd run build
```

Контроль переводов и проверка наличия ресурсов, формата GLB и SHA-256 входят в сборку. Публиковать нужно весь `frontend/dist`, включая `encyclopedia/ennorath/`.

## Проверки

```powershell
npm.cmd run test:unit
npm.cmd run lint
npm.cmd run build
npm.cmd run test:ui
```

`e2e/knowledge.spec.js` проверяет загрузку настоящих моделей всех 54 профилей, уровни, конную модель, анимацию и паузу, оружие, поиск, мобильную формацию, восстановление после ошибки и локализованный выбор версии с недоступным 2.02. API авторизации в этих сценариях подменён анонимным ответом; игровые ресурсы не подменяются.
